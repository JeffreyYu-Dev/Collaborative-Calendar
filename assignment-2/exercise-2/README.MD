I just bought a new M5 Macbook pro previously I was on arch linux, so I had to do things differently.
I have to use CMakeLists to build my project and link everything before while on arch the compiler already knew where it was already.

To run:

- You will need cmake

Exercise One

```
    cd exercise-1
    mkdir build
    cd build
    CMake ../CMakeLists.txt
    make
    ./exercise-one
```

Exercise Two

```
cd exercise-2
mkdir build
cd build
CMake ../CMakeLists.txt
make
./exercise-two
```
